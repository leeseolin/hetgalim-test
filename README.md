# 헷갈리는 말 테스트

한국인이 자주 헷갈리는 맞춤법과 표현을 짧은 퀴즈로 익히는 웹 서비스입니다. 긴 문법 설명을 읽기 전에 문제를 풀고, 결과 화면에서 오답과 해설을 함께 확인할 수 있습니다.

**[서비스 바로가기](https://hetgalim-test-chi.vercel.app)**

## 프로젝트 배경

맞춤법을 검색하면 정확한 설명을 찾을 수 있지만, 실제 문장에서 구분할 수 있는지는 다시 확인하기 어렵습니다. 설명을 읽는 데서 끝나지 않고 직접 풀고 복습하는 짧은 학습 흐름을 만들고자 했습니다.

또한 표현이 늘어날 때마다 페이지와 메타데이터를 반복해서 작성하지 않도록, 콘텐츠 데이터 하나가 목록·상세 페이지·관련 테스트·검색 노출 정보로 이어지는 구조를 목표로 했습니다.

## 주요 기능

- 표현별 10문제 객관식 퀴즈와 진행률 표시
- 점수 계산, 오답 모아보기, 문제별 해설
- 퀴즈별 10초 요약, 구분법, 실제 예문
- 관련 테스트 추천과 모바일 반응형 화면
- 표현별 정적 페이지와 검색 메타데이터 자동 생성
- sitemap, robots.txt, 네이버 서치어드바이저 인증

## 핵심 설계

### 콘텐츠 중심 구조

퀴즈 콘텐츠를 타입이 정의된 데이터 객체로 관리합니다. 객체를 추가하면 메인 목록, 상세 페이지, 관련 테스트, 정적 경로와 sitemap에 함께 반영됩니다. 콘텐츠 수가 늘어나도 라우팅 코드를 반복해서 만들지 않아도 됩니다.

### 서버와 상호작용 영역 분리

페이지 콘텐츠와 메타데이터는 서버에서 정적으로 생성하고, 문제 진행·답안 선택·점수 계산처럼 브라우저 상호작용이 필요한 부분만 클라이언트 위젯으로 분리했습니다.

### 검색을 고려한 페이지 생성

각 퀴즈는 고유 URL과 제목, 설명, 키워드, Open Graph 정보를 가집니다. 현재 30개의 퀴즈 경로를 포함해 총 38개 페이지가 빌드 시 정적으로 생성됩니다.

## 프로젝트 구조

```text
src/app          라우팅과 메타데이터
src/f1_pages     서버 페이지 구성
src/f2_widgets   퀴즈 진행과 결과 UI
src/f4_entities  퀴즈 데이터와 도메인 타입
src/f5_shared    공통 UI
```
